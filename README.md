# Three-wattled Bellbird elevational dynamics in southern Costa Rica

Data and R code supporting the manuscript:

> **Integrating acoustic monitoring and citizen science reveals seasonal and long-term elevational dynamics of the Three-wattled Bellbird in southern Costa Rica**

**Authors:** Jimy Barrantes-Madrigal, Randall Jiménez-Borbón, Carolina Esquivel Dobles, and Mónica Retamosa-Izaguirre

## Overview

This repository contains the analysis-ready data and R scripts used to examine seasonal movements, landscape associations, and long-term elevational dynamics of the Three-wattled Bellbird (*Procnias tricarunculatus*) in southern Costa Rica and the broader Costa Rica–Panama region.

The study combines passive acoustic monitoring from 45 sites in and around the AmistOsa Biological Corridor with citizen-science observations from eBird and iNaturalist. Acoustic recordings were collected between May 2023 and July 2024, whereas the eBird analyses cover 2000–2025. An embedding-based acoustic classifier developed using Perch and the Hoplite framework was used to identify bellbird vocalizations. All candidate detections retained for the ecological analyses were manually reviewed.

The repository supports five components of the study:

1. Independent evaluation of the acoustic classifier.
2. Seasonal and elevational patterns in acoustic detection probability.
3. Seasonal associations between detection probability and landscape and environmental variables.
4. Long-term changes in elevational reporting patterns derived from complete eBird checklists.
5. Identification of spatial–seasonal records contributed by acoustic monitoring that were absent from the historical eBird archive.

## Data description

### Acoustic monitoring

Autonomous recording units were deployed at 45 sites between May 2023 and July 2024. Recorders sampled for five minutes followed by a 15-minute pause between 05:00 and 17:59. Recordings were collected at a sampling rate of 44.1 kHz and a bit depth of 16 bits.

The original audio archive is not included because of its size. The repository contains the manually validated detections and sampling-effort summaries required to reproduce the statistical analyses.

The main acoustic data products are:

| Data product | Description |
|---|---|
| Classifier annotations | Manual annotations used to construct the independent classifier test dataset. |
| Classifier predictions | Prediction scores for five-second windows in the independent test recordings. |
| Classifier evaluation windows | Analysis-ready table containing the prediction score and manual binary label for every test window. |
| Validated acoustic detections | Candidate predictions at the operating threshold that were manually confirmed as Three-wattled Bellbird vocalizations. |
| Detection-day summaries | Number of days with at least one confirmed detection and number of effective sampling days for each site and month. |

The independent classifier evaluation comprises 212 one-minute recordings divided into 2,544 five-second windows. Manual annotation identified 531 vocalizations distributed among 404 positive windows; the remaining 2,140 windows were negative. The classifier was evaluated at an operating threshold of 0.01 selected before independent testing.

### Citizen-science data

Complete eBird checklists from Costa Rica and Panama were used to estimate reporting probability and long-term elevational patterns between 2000 and 2025. The eBird Basic Dataset and associated sampling-event data are not redistributed in this repository. To reproduce the processing from the original observations, users must request the corresponding data directly from [eBird](https://ebird.org/data/download) and place the downloaded files in `data/raw/` using the names specified in `preprocessing.R`.

iNaturalist records were used under a data-sharing agreement and are not included in the public repository. Access inquiries should be directed to Naturalista Costa Rica at `naturalistacr@gmail.com`. The analysis scripts clearly identify any steps that require these restricted records.

### Spatial and environmental data

The analyses use the following spatial and environmental information:

- Boundary of the AmistOsa Biological Corridor and the study-area extent.
- Costa Rica 2023 land-cover data.
- Elevation and mean annual precipitation from WorldClim v2.1.
- Human Footprint data for 2020.
- H3 resolution-6 grid cells for Costa Rica.

Third-party spatial layers are included only when their licenses permit redistribution. Otherwise, `preprocessing.R` documents the expected file name and source needed to reproduce the analysis.

## Analytical workflow

Run the scripts from the root directory of the project in the following order:

```r
source("scripts/preprocessing.R")
source("scripts/02_model_performance.R")
source("scripts/03_predicted_seasonal_patterns.R")
source("scripts/04_landscape_influence.R")
source("scripts/05_long-term_migration_analysis.R")
source("scripts/06_additional_grids_acoustic_detections.R")
```

`preprocessing.R` must be completed successfully before running the numbered analysis scripts. All paths are defined relative to the project root using the `here` package.

## Main analyses

### Classifier performance

Classifier performance is evaluated using precision, recall, specificity, accuracy, F1 score, receiver operating characteristic area under the curve, and precision–recall area under the curve. The independent test data are used only for final evaluation and not for selection of the operating threshold.

### Seasonal acoustic patterns

Acoustic detections are aggregated by site and month. The response is specified as the number of detection days relative to the number of effective sampling days. A binomial generalized additive model includes a cyclic smooth for month, season-specific smooths of elevation, a parametric season effect, and a random effect for site.

The reproductive season is defined as March–August and the non-reproductive season as September–February.

### Landscape associations

Acoustic sites and spatially clustered eBird observations are analyzed as sampling units. Landscape and environmental predictors are calculated within 1-km buffers and standardized before model fitting. The binomial model evaluates interactions between each continuous predictor and season while accounting for the overall effect of data source.

### Long-term elevational dynamics

Complete eBird checklists are aggregated by year, week of the year, and 100-m elevation band. A quasibinomial generalized additive model represents joint nonlinear variation across week, elevation, and year using a three-dimensional tensor-product smooth. Predictions are summarized for lowland, mid-elevation, and highland zones.

### Additional acoustic records

Acoustic and eBird observations are assigned to H3 resolution-6 cells and summarized by calendar month. An additional acoustic record is defined as an acoustic-positive cell–month combination from 2023–2024 without a positive eBird record in the same cell and calendar month in the 2000–2025 archive. This definition does not imply a range expansion or the first historical occurrence of the species in the broader region.

## Software requirements

The analyses were developed in R. The long-term eBird workflow reported in the manuscript used R 4.4.2. Major package dependencies include:

```text
auk, basemaps, cageo, crgeo, crhexgrids, dbscan, DHARMa, dplyr,
emmeans, exactextractr, ggplot2, ggsci, ggspatial, glmmTMB, gratia,
here, landscapemetrics, lubridate, MASS, mgcv, patchwork, pROC,
PRROC, purrr, raster, readr, rio, sf, sjPlot, stars, terra,
tidyterra, tidyr
```

The `cageo`, `crgeo`, and `crhexgrids` packages are installed from GitHub:

```r

remotes::install_github("ManuelSpinola/cageo")
```
